# Design Systems V4 — Ten Unique Treatments, One Approved Content Set

> **Core rule:** Every LP retains the same approved symptom-led copy, symptom cards, provider-photo placeholder, bio placeholder, verified-review placeholder, non-diagnostic disclosure, chat launcher, Privacy Policy, Terms & Conditions, and Seahawks-styled top phone number. Only the visual treatment, layout rhythm, hierarchy, and responsive composition change.

## Shared Research-Based Rules

| Rule | Applied Standard |
|---|---|
| Content priority | Top phone, one headline, short supporting line, one CTA, then symptom recognition cards |
| Mobile density | One primary action per first screen; compact but readable hierarchy |
| Target size | Primary controls, phone chip, chat, and FAQ controls are 44px or larger; all other interactive targets meet or exceed 24px minimum |
| Health literacy | Plain language, one idea per sentence, short chunks, no diagnosis or unapproved treatment/coverage claim |
| Shared phone style | Blue `#002244` background and green `#69BE28` text, visibly placed at the top of every screen |

## Ten Design-Cycle Checklist

| Cycle | Applied Change |
|---:|---|
| 1 | Keep the top phone number prominent yet separate from the symptom CTA |
| 2 | Preserve one message and one action above the fold |
| 3 | Give every route a different hero composition |
| 4 | Give every route a different symptom-card pattern |
| 5 | Give every route a different provider/review framing method |
| 6 | Maintain mobile control sizes and reachable CTA placement |
| 7 | Check light/dark contrast and type hierarchy per palette |
| 8 | Keep health language plain, non-diagnostic, and easy to scan |
| 9 | Ensure the legal, chat, and disclaimer elements appear without dominating the page |
| 10 | Verify each desktop and mobile page reads as a distinct design, not a color swap |

## Asset Reuse

The existing original hero asset library is reused intentionally across V7–V10. Distinct layout, framing, overlays, color systems, card patterns, and responsive behavior create the unique visual treatment without unnecessary new image generation.
